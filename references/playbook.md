# 一页纸玩法索引

按「你想接下来发生什么」选一个玩法。每张卡有适用情境、输入、做法、可复制的模板、原创示例和验收点。可说「用 `$toyota-one-page` 的 W02 帮我找出接下来两个月哪段工作扎堆」，也可以直接说需求，不必记卡号。

| 卡号 | 要做的事 |
|---|---|
| F01 | [定对象与目的](cards/foundations.md#f01-定对象与目的)——「整理一下」还不是任务定义。 |
| F02 | [Excel1 发散再筛选](cards/foundations.md#f02-excel1-发散再筛选)——没开始写，材料和念头还散。 |
| F03 | [Logic3 一句话与读者三问](cards/foundations.md#f03-logic3-一句话与读者三问)——需要别人看懂或拍板。 |
| D01 | [预演追问与问答清单](cards/documents.md#d01-预演追问与问答清单)——找没预料到的质疑或答不上来的问题。 |
| D02 | [做一眼能看全的资料](cards/documents.md#d02-做一眼能看全的资料)——意思对了，但读者找不到全貌。 |
| D03 | [重整旧资料](cards/documents.md#d03-重整旧资料查出自己的理解缺口)——换结构梳理原件，找出漏写和冲突。 |
| D04 | [PPT 与总览页互转](cards/documents.md#d04-ppt-与总览页互转)——一页结构和现场视觉辅助各司其职。 |
| D05 | [多场访问与出差报告](cards/documents.md#d05-多场访问与出差报告)——逐场写要点，再合并出本趟结论。 |
| M01 | [会前比较候选方案](cards/meetings.md#m01-会前比较候选方案)——挑要带上桌的方案，不替与会者做决定。 |
| M02 | [用白板推进会议](cards/meetings.md#m02-用同一张白板推进会议)——现场收敛、拉回跑题、确认已定与未定。 |
| M03 | [会议纪要](cards/meetings.md#m03-会议纪要不是逐字稿)——已发生的会，不把建议记成决定。 |
| W01 | [一天可执行的计划](cards/work.md#w01-写一天可执行的计划)——列能动手的工作并排执行顺序。 |
| W02 | [两个月排程](cards/work.md#w02-两个月排程找负荷峰值)——看工作量何时扎堆，而非按单项优先级排序。 |
| W03 | [重要、紧急、可委派分别排序](cards/work.md#w03-重要紧急可委派分别排序)——找现在先动手的一项。 |
| W04 | [协商与面谈预演](cards/work.md#w04-协商与面谈预演)——准备自己的请求、答复、条件和退路。 |
| W05 | [接受反馈](cards/work.md#w05-听到批评先把话落到纸上)——把模糊评价转成例子、期待和可改动作。 |
| W06 | [指出问题](cards/work.md#w06-指出问题时让双方看同一张纸)——让双方的信息在同一张纸上，找共同改法。 |
| W07 | [给不可控工作留缓冲](cards/work.md#w07-给不可控的工作留缓冲)——临时工作常打断全日计划。 |
| G01 | [年度目标与七个筛选视角](cards/goals.md#g01-年度目标大枚举与七个筛选视角)——先铺开，再保留各类取舍的理由。 |
| G02 | [把决心换成第一步](cards/goals.md#g02-把决心换成第一个看得见的动作)——愿望已明确，但没开始。 |
| G03 | [零标记却舍不得放下](cards/goals.md#g03-零标记却舍不得放下的愿望)——找自己真正愿意投入的理由。 |
| G04 | [日复盘](cards/goals.md#g04-日复盘继续卡点下次试什么)——找继续做的、卡点和下一轮的试验。 |
| L01 | [新闻怎么用](cards/learning.md#l01-新闻怎么用而不只摘标题)——捡出重要新闻和自己的应用假设。 |
| L02 | [书影感想与推荐](cards/learning.md#l02-书影感想与推荐页)——表达体验或告诉别人值不值得看。 |
| L03 | [读书应用](cards/learning.md#l03-读书应用作者观点不等于我的试验)——书里的方法怎么在自己的情境里试。 |
| L04 | [地点联想记忆](cards/learning.md#l04-用熟悉路线做地点联想记忆)——在熟悉路线的各个位置装上待记信息。 |
| L05 | [月度行为记录](cards/learning.md#l05-一个月一页记录行为)——低负担记做没做，不把缺记录看成没做。 |

**相近场景怎么选**：只改视觉层次选 D02；要弄懂或查漏选 D03。想让几件事今天做得完选 W01；先选谁更该做选 W03；总计划常被意外打断选 W07。知道该做什么但卡在第一步选 G02；多项愿望冲突或从众动机不明选 G01／G03。开会过程可以串 M01 → M02 → M03，但只要纪要时别强行补一次主持流程。
