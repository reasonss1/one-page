# 基础｜先定目的，再定操作

以下例子均为原创。模板是可编辑的交付骨架，不是必填表；同一素材按不同目的可以走不同卡。

## F01 定对象与目的

**何时用／输入**：任务只说「整理一下」，或有多类收件人。需要知道读者、他们已知什么，以及读完要了解、批准或执行什么。

**做法**：先给自己写一张反向 Logic3：谁是主要接收人 → 他现在知道什么、还缺什么 → 看完要发生什么。目的不清时，先填三问再倒推出 1P。多个对象优先选实际决策人；目标相冲突时分成不同页，不写一页大而全的空话。

**模板**：`主要读者｜已知/缺口｜预期反应或决定｜本页目的：帮助谁在什么情况下做什么`

**例**：换活动室的同一组材料，馆长那页请决定是否开放周末；志愿者那页只说开门时间、钥匙在哪、谁值班。不用给志愿者重讲预算申报。

**验收**：目的不能只写成「汇报进展」，应看得出读者下一步可做什么。

## F02 Excel1 发散再筛选

**何时用／输入**：卡在第一句，手上有零散事实、任务、选项或念头。需要一个待答问题和现有信息。

**做法**：① 绿：定一个问题，可加日期。② 蓝：开一列小格，一格一词或短句；先写不评判，不凭空补事实。纸笔可从 8 个小格起步，信息多再扩至 16、32 或 64 格；卡住就先画格，写约 90 秒至 3 分钟。③ 红：另起一轮按对题目有用的标准标记、排序或归类；纸笔约 1 至 3 分钟。自用理清即可，不为凑格式转 Logic3。

**模板**：`日期 / 待答问题 → 素材格：1… 2… → 筛选标准：… → 标记、排序及首选：…`

**例**：问「用户为什么找不到借书入口？」把指引文字、入口层级、读者反馈分格，再按「证据是否直接」和「改完是否容易验证」筛出先试重命名菜单，不先改整个首页。

**验收**：找得到从哪些候选、按什么标准筛到结论；写完才评判。

## F03 Logic3 一句话与读者三问

**何时用／输入**：信息已成形，要交给人看；需要受众、目的、证据与待核实信息。

**做法**：先写一条能传达结论、请求或条件的 1P。反推读者最多三个关键问题，每问先直答，再放最多几个有区分度的依据。想不出可以从 What／Why／How 找切口，但可以用两个 How，也可以只答两问。答完回头改 1P；标题已讲清就不重复。需推进时收在动作和条件，未知人名或时间留待确认。

**模板**：`1P：…｜读者问① / 直接答＋依据｜读者问②…（可删）｜动作 / 已知条件`

**例**：「请同意本周只在东门试标识，雨天读不读得清尚待测。」读者先问为什么选东门，再问什么结果会触发扩大试点；不另添一段泛泛背景。

**验收**：删去问题标题后，答案依然能让读者判断；已发生、建议和未知不会混起来。
