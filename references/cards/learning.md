# 学习与日常记录｜理解、表达、应用分开做

## L01 新闻怎么用，而不只摘标题

**何时用／输入**：收藏很多新闻，想挑值得读的并转成工作提醒。需要标题和正文、来源或摘录；只有标题则不要补编内容。

**做法**：先用 Excel1 写候选标题，从中挑最想追的最多三条。每条用 Logic3 回答：我为什么关心、原文最重要的事实是什么、我可以在哪个场景用它。来源和时间能核则注明；推测不混成新闻结论。要核最新事实时再查来源，不假装读过。

**模板**：`新闻 / 出处｜为什么挑｜原文信息｜我的用途或待核实动作｜1P`

**例**：读一条图书馆延长开放时间的通知，把「周三开放」和「想让本地馆试晚间开放」分开写；应用是先问本馆是否收到夜间需求，不断言必有成效。

**验收**：从候选里确实作了取舍；转用时清楚标出哪部分是读者自己的判断。

## L02 书影感想与推荐页

**何时用／输入**：看完想记感想或推荐给某人；需要对象、作品内容或笔记、允许的剧透程度。

**做法**：先试着写一句体验，不顺就先写问答。自用时答「我为什么看、留下了什么、还想试或追问什么」；推荐时改为「哪个点值得看、为什么、适合谁」。选一两个具体情节、论点或观感作为依据，区分作品内容与自己的评价；不编未提供的内容。

**模板**：`书/片｜写给谁｜一句感受/推荐｜具体点｜理由｜适合/不适合或后续`

**例**：推荐一部节奏慢的原创虚构纪录片给想了解地方工艺的朋友：值得看的是制作者处理失败的镜头；如果朋友只想快学操作，说明不是教程。

**验收**：给别人看不是复述整个剧情；给自己看不是假装客观评分。

## L03 读书应用：作者观点不等于我的试验

**何时用／输入**：不想只做摘要，手边也有可试的问题。需要原文或笔记中的观点、自己的实际情境。

**做法**：先记「作者在解决什么、给了什么思路」并注明出处。若已有 Logic3 摘要，可保留前两问，另存一页把末问从「作者给的办法」改为「我怎么用」。写有什么类似处、哪些条件不同，再选择可先试的一步。写预期信号与复查方式，保留不适用时的备选。尚无可用场景时如实提问，不强造收益。

**模板**：`作者主张/出处｜我的场景与差异｜我要试的一个动作｜记录什么｜何时再评估`

**例**：从某本书读到减少工作切换的观点。不是写「作者说我每天会更高效」，而是在自己两次备课中各试 25 分钟不切窗口，记未完成条目，再判断是否适用。

**验收**：能指出哪句是作者观点，哪句是自己的动作；试验的好坏可观察而非预先保证。

## L04 用熟悉路线做地点联想记忆

**何时用／输入**：要背术语、词义或词对；输入一条熟悉稳定的路线和待记清单。

**做法**：在一页画有顺序的位置格，先填熟悉路线上的地点或物，再把一项词或含义放进同格，想象两者如何发生联系。顺着路线不看词表回忆，找出漏点，替换难想的联想。列表长就分段或换路线；从少量位置起步，不承诺背诵效果。

**模板**：`索引→地点/物｜要记的词和义｜独特联想｜回忆✓/待练`

**例**：路线从门垫到水杯再到窗台。门垫对应 margin，想象门垫四周故意空出一圈；水杯对应 volume，联想杯壁刻度。走一遍，只看地点说词义。

**验收**：地点按熟悉顺序排列，同一匹配可用联想回忆，不做单纯词表。

## L05 一个月一页记录行为

**何时用／输入**：想看一个可持续动作的时间分布和变化，不需要对体重或健康作判断。需选一个行为、月份、低负担的观察规则。

**做法**：按实际天数开日期格，约定同一日常提示（例如收桌后），把页放在顺手的位置，每天只作一次简短记录。颜色或 ✓／·／空白区分已做、没做和缺记录；记录连续数值时，可用两种颜色或箭头标「比上次高」与「持平或更低」，只表变化方向，不作好坏评价。每周观察中断通常发生在什么情境，再只调一个提示或难度；别补填缺失数据。

**模板**：`月份 / 行为 / 提示时点｜01…月底（日格）｜简短观察｜只改一个条件`

**例**：晚饭后读两页。✓ 表示读了，· 表示没做，空着表示忘记记。发现周六常没记，不断言没读，改为把记号笔放在书上再观察。

**验收**：记录本身足够轻，能区分未做与缺记录，不用个别案例推断减重或健康效果。本卡只提供记录结构，不给减重处方。
