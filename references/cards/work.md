# 工作与沟通｜计划、负荷、反馈

## W01 写一天可执行的计划

**何时用／输入**：早上想安排今天，或下班前想整理明天。输入任务、固定时点、可用时间；无可靠耗时可先排序，不精确估算。

**做法**：一格一个可动手的动作，不写「跟进项目」这类大类。先列完，再按先后排；可把同类小事合并，为需要专注的事留连续时段。有依赖先满足依赖，容量不足就另分「今天不做」，避免把愿望当日程。

**模板**：`日期 / 可用时段｜编号-动作-前置或截止｜合并处理项｜留到哪天｜现在开始…`

**例**：两封确认信一起发，再留连续 45 分钟写提纲；寄样品要等对方给地址，先把「索取地址」列成今天的动作。

**验收**：开工时知道按什么顺序做；每项都能用一个动作开头。

## W02 两个月排程找负荷峰值

**何时用／输入**：未来几周重活扎堆，想调完成窗或重新分配。需要未来两个月主要事项、完成时间窗、复杂度及必要依赖；可用个人或团队视图。

**做法**：逐格填主要事项而不先排时间；按半月或约定周期标记完成窗，重活重复标记或标为「重」。再按周期分栏观察密度与重活，不把标记当真实工时。保留刚性期限；能动的任务可前移、错峰，或在承接人确认后交接。跨多窗的长任务另标关键投入期；未知期限单列。

**模板**：`窗口 1｜窗口 2｜窗口 3｜窗口 4｜待定`，每项附 `重活？/ 固定？/ 依赖 / 拟调整及确认人`。

**例**：上半月有盘点和年报两项重活、月末还有固定审计。把可提前的库存标签准备前移；不自行把审计挪期，也不把「可委派」当已交接。

**验收**：可指出哪个窗口拥挤、拥挤是任务多还是重活多，以及哪项是真的可调整。

## W03 重要、紧急、可委派分别排序

**何时用／输入**：待办互相争时间，不能只按截止日。需要任务、期限、影响、依赖、可商量的承接人。

**做法**：Excel1 分开圈重要项、紧急项，再标可委派项；重要与紧急每类先挑少数，不合成一个不透明分数。第三维也可换成「做了会解除哪个依赖」。需要动手时给先做、为什么、怎么挪剩余；委派写交付条件并等确认。

**模板**：`任务｜重要依据｜截止/后果｜前置｜可委派且已确认？ → 首项→后续`

**例**：两分钟确认当天的来访门禁先做；下午给同事的方案更重要，确认门禁后留整块时间；下周用的照片整理可先询问他人是否能接。

**验收**：排序尊重固定时点和前置条件，没把所有事都标成高优先。

## W04 协商与面谈预演

**何时用／输入**：要申请资源、谈延期、沟通分歧。需要对方角色、真实诉求、手头证据和可商量范围。

**做法**：先列对方有可能追问的内容，圈最可能或最会改变决定的几个。把最值得练的最多三问放进 Logic3，用对方平时会说的话来问，再准备短答、证据和无法承诺处。给自己写一句开场请求和一条可接受退路。会前练一次「对方追问 → 我直接回应」，不编对方态度或筹码。

**模板**：`我想商量…｜对方可能问…｜答复与依据｜可接受替代｜待对方确认`

**例**：申请把交接推迟两天。对方可能问这两天谁顶班，未知就说「先对齐排班再承诺日期」，而不是说人已经安排好。

**验收**：能用一句话讲请求；没把自己的推测当成对方的立场。也可接 D01 的问答页。

## W05 听到批评，先把话落到纸上

**何时用／输入**：接受反馈时，几件事混在一起、难辨具体指什么。需要对方的话、能确认的情境；没有许可不默认录音。

**做法**：将反馈拆进小格，记「对方怎么说」和指向的具体工作，个人感受另放。把模糊评价改成待澄清的问题，请对方举例、说清期待；把确认的工作改法写一次，保留不认同或尚不明白处。不是要求忍受攻击，也不自动把所有批评当事实。

**模板**：`收到的反馈｜发生在哪/可核实吗｜我还要问什么｜已确认期待｜我能试的改法`

**例**：「交接老是写不清」先确认是哪个班次、缺了什么字段。对方指出昨晚的钥匙去向没写，就先试在交接单补一栏，不把一句批评等同于否定人。

**验收**：至少分开评价、实际例子和可改动作；事实尚不明时留下澄清项。

## W06 指出问题时让双方看同一张纸

**何时用／输入**：要指出工作问题并听到对方解释，不只是单方面下结论。需要可核实例子、影响与对方陈述。

**做法**：写在双方都能看的共享页：观察到什么，造成什么影响，对方怎么理解。双方各自的说法并列，确认一致点和不同点；再商量一个小改法和复查信号。敏感个案仅在合适范围使用，不公开贴出私人反馈。

**模板**：`观察 / 影响｜我的解释｜对方说明｜共同确认 / 待核对｜试改 / 复查`

**例**：交接漏了关键字段。主管列出两次漏项，值班员补充表单在手机上最后一栏被折叠；先测试改字段位置，而不是直接定性「不认真」。

**验收**：纸上看得到双方的信息与待核对处；改法针对工作行为，不贴人格标签。

## W07 给不可控的工作留缓冲

**何时用／输入**：日计划经常被临时咨询、报修等打断。需要可用工时、已有突发记录、必须保障的任务。

**做法**：把工作分为能排程的、难预先排程的，按已有记录估一个缓冲；没有数据就明确先试的假设。只给可控容量排主动任务；若突发超过缓冲，记录挤掉的是哪件，重新确认计划。没变少的工作量不能报告为已下降。

**模板**：`总可用时段｜突发预留（依据/假设）｜可控计划量｜超出时推迟哪项｜实际复查`

**例**：门店每天零散来客难预测；根据最近几天的记录给咨询留一段弹性，主动任务只排能保护的整理和回访，不把全天塞满。

**验收**：看得出哪段可控、哪段只是估计；不把留白误当空闲或产出。
